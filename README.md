## Featured Project

### [Secure AI Gateway](https://github.com/sumeet9shah/secure-ai-gateway)
A self-hosted gateway that sits between users and a local LLM. Every prompt is authenticated via Keycloak (JWT RS256), scored by a threat detection engine mapped to MITRE ATLAS, and either blocked or forwarded. Nothing reaches the model without passing through auth, RBAC, and risk scoring. Role-specific SOC dashboards surface audit logs and blocked prompt metadata in real time.

`FastAPI` `Keycloak` `JWT` `Ollama` `Streamlit` `Oracle Cloud` `Python`
